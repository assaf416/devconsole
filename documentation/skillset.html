🔄 workflow פיתוח מלא

פתיחת Issue בעברית — כותרת, תיאור שינוי, שעות משוערות, בדיקת Cucumber מוצעת, פתרון מוצע.
יצירת branch — שם לפי ST-XXX-תיאור-באנגלית.
כתיבת Cucumber בעברית — feature file עם # language: he, step definitions.
מימוש — הוספת קוד/תיקון. Ruby, Sinatra, Go לפי הצורך.
ריצת בדיקות — bundle exec cucumber. ירוק לפני commit.
Commit + Push + PR — PR לתוך main, ממתין ל-CI.
Merge + סגירת Issue — עדכון body ב-Issue עם שעות בפועל.
